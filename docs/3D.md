# 3D — Capa de visualización

Arquitectura de la escena 3D de este sitio. Fuentes de método: skills instaladas
(`.opencode/skills/3d-web-experience`, `react-three-fiber`) y `docs/TOOLS.md`.

## Principios

- El 3D **nunca** es el único canal de información: todo el contenido vive en HTML.
- Sin WebGL, sin soporte o con `prefers-reduced-motion` → composición CSS estática
  equivalente. El usuario no pierde nada, solo movimiento.
- Fuera del viewport → pausa (`frameloop="never"`), dentro → reanuda. Sin renders
  a fondo de pantalla.
- Latencia por debajo del contenido: la escena se monta con `dynamic({ ssr:false })`
  y con retardo de 180 ms tras el primer pintado.
- Sin controles de órbita ni dependencia del ratón: la interacción es parallax
  sutil (derecho/izquierdo del puntero) y deriva con el scroll.

## Punto de entrada

`src/components/three/HeroCanvas.tsx`

```
HeroCanvas (host, pointer-events-none, absolute inset-0)
├── hasWebGL() && !prefersReducedMotion() ?
│   ├── Sí + loaded + visible → <NetworkScene tier={tier} active={visible} />
│   └── No (o fuera de viewport) → <StaticFallback />
```

| Señal | Acción |
| --- | --- |
| Sin WebGL / reduced-motion | `StaticFallback` (gradientes + grid CSS + nodos de luz) |
| Con WebGL | carga diferida (180 ms) de `NetworkScene` |
| Sale del viewport (IO +250px) | `active=false` → pausa del render |
| `prefers-reduced-motion` en caliente | desmonta la escena y vuelve al fallback |

## Escena: `NetworkScene.tsx`

Concepto **Sistema / Developer / Network**: un grafo de nodos y aristas sobre una
malla de referencia.

- Distribución de nodos determinista (`mulberry32` con semilla fija): misma
  composición en todos los dispositivos, sin saltos entre visitas.
- Capas: grid → líneas (aristas con opacidad por distancia) → nodos → partículas.
- Movimiento: parallax con el puntero (lerp amortiguado), deriva lenta ligada al
  scroll, pulso de opacidad por nodo. Nada que dependa del usuario para entender
  la página.
- Colores: tokens del sitio (`--brand #00FF88`, `--system #5865F2`, `--data #45C8FF`).

## Calidad: `quality.ts`

| Tier | DPR | Uso previsto |
| --- | --- | --- |
| `high` | `[1, 1.75]` | escritorio con retina |
| `low` | `[1, 1.25]` | móvil, puertos integrados, poca potencia |

`hasWebGL()` prueba un contexto real una sola vez y no deja contexto abierto.

## Reglas

- `pointer-events-none` en el host y `pointerEvents: "none"` en el `<Canvas>`:
  el 3D **jamás** puede interceptar clics (CTAs, contador, strip en vivo).
- El contenido por encima lleva `relative z-10`; el canvas vive por debajo.
- Sin `OrbitControls`, sin HUD de cargado: si tarda, no se ve.
- Si aparece interacción con el usuario (clicks), debe apagar `active` y notificarse
  en las caché de intención (`userRequested`) para no pelear por el foco.
